# Nighterminal 使用说明

一个 Windows 上的半透明毛玻璃终端。后端是 Rust + ConPTY，前端是 xterm.js，所以它跑的是真正的
PowerShell / cmd，不是模拟器。

---

## 1. 界面

```
┌──────────────────────────────────────────────────────────┐
│ ▶_  [ powershell ×] [ nighterminal ×]  +      ⚙ ─ □ ✕   │  标题栏 / 标签栏
├──────────────────────────────────────────────────────────┤
│                                                          │
│  PS C:\Users\you>                    │                   │  终端区（可分屏）
│                                      │                   │
│                                      ├───────────────────┤
│                                      │                   │
├──────────────────────────────────────────────────────────┤
│ ● powershell / 103×24   2 panes           DOM / acrylic  │  状态栏
└──────────────────────────────────────────────────────────┘
```

**标题栏**：左边是标签页，`+` 新建，链路图标是 SSH 快速连接；右边齿轮是设置，然后是最小化 /
最大化 / 关闭。中间空白处可以
拖动窗口，双击最大化。

**状态栏**（从左到右）：

| 项 | 含义 |
| --- | --- |
| ● | 绿色＝shell 正常，红色＝shell 已退出 |
| `powershell` | 当前 pane 跑的是哪个 shell |
| `103×24` | 当前 pane 的列数×行数 |
| `2 panes` | 当前标签页分了几屏（未分屏时不显示） |
| `DOM` | xterm 使用的渲染器 |
| `acrylic` | 系统给到的毛玻璃材质：`acrylic` / `mica` / `solid`（无毛玻璃时会自动改用不透明背景） |

全屏 TUI（vim、htop、lazygit、Claude Code 等）接管画面时，状态栏会自动收起把这一行让出去
（标签栏仍在，不然就没有出口了），退出后自动回来。

## 2. 标签页

| 操作 | 方式 |
| --- | --- |
| 新建 | `Ctrl+Shift+T`，或点 `+` |
| 关闭 | 标签上的 `×`、中键点标签，或 `Ctrl+Shift+W` |
| 切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab`，或 `Ctrl+(Shift+)PageDown` / `Ctrl+(Shift+)PageUp` |
| 跳到第 N 个 | `Ctrl+Alt+1` … `Ctrl+Alt+9` |
| 重排 | 按住标签左右拖动 |

拖拽重排会同步所有按序号的操作：`Ctrl+Tab` 的轮转顺序、`Ctrl+Alt+N` 指向的标签、会话恢复的顺序，
都跟着你眼睛看到的排列走。

标签名跟着 shell 报告的标题走，并会压缩成最后一段：`D:\Projects\Nighterminal` 显示成
`Nighterminal`，`powershell.exe` 显示成 `powershell`。

在 shell 里敲 `exit` 会关掉所在的 pane；如果那是标签页里最后一个 pane，标签页跟着关；关掉最后一个
标签页则退出程序。

**shell 起不来时不会静默消失**：如果 shell 根本起不来（通常是配置里的 shell 路径写错了），或者
起来后 1.5 秒内就退出，这个 pane 会留在屏幕上并打出一行红字，标签上的圆点变红，方便你看清错误再
手动关掉。关掉那个失败的 pane 后红点熄灭。

## 3. 分屏

| 操作 | 快捷键 |
| --- | --- |
| 向右切一屏 | `Ctrl+Shift+D` |
| 向下切一屏 | `Ctrl+Shift+E` |
| 移动焦点 | `Alt+←` `Alt+→` `Alt+↑` `Alt+↓` |
| 与相邻 pane 换位 | `Ctrl+Alt+←` `→` `↑` `↓` |
| 关闭当前 pane | `Ctrl+Shift+W` |

可以任意嵌套：先左右切，再对右半边上下切，就得到"左边一整列 + 右边两格"。

- **换位**交换的是两个 pane 的位置，终端内容、滚动历史、正在跑的程序都原样带走；焦点跟着
  pane 走，所以按住 `Ctrl+Alt` 连续按方向键能把一个 pane 一路挪到想去的位置。（不用
  `Ctrl+Shift+方向键`，是因为那是 PSReadLine 的按词选择，不该被抢走。）
- **拖动分隔条**可以调整比例，最小 8%。
- **焦点 pane** 会有一圈很淡的青色描边，未聚焦的 pane 字会稍微变暗；鼠标点哪个 pane 就切到哪个。
- **新 pane 继承当前 pane 的工作目录**（需要 shell 集成，见第 7 节），否则用设置里的起始目录。
- `Alt+方向键` 是**按屏幕位置**找最近的邻居，不是按分割树的结构 —— 嵌套之后"树上的邻居"经常不是
  眼睛看到的那个。

## 4. 复制粘贴

| 操作 | 方式 |
| --- | --- |
| 复制选区 | `Ctrl+Shift+C`、`Ctrl+Insert`，或选中后点右键 |
| 粘贴 | `Ctrl+V`、`Ctrl+Shift+V`、`Shift+Insert`，或没有选区时点右键 |
| 选择 | 鼠标拖选 |

`Ctrl+C` **没有被拦截**，它始终作为中断信号送给 shell —— 这是终端里 `Ctrl+C` 该有的行为，要复制
请用 `Ctrl+Shift+C`。

粘贴走的是 xterm 的 `paste()`，所以 app 要求 bracketed paste 时会被正确遵守：多行内容作为一整块
进入输入框，不会被逐行执行 —— Claude Code、vim 这类程序尤其依赖这一点。

**剪贴板里是图片时**（截图工具刚截的那种），终端本身没有"图片"这个概念，于是原始的 `Ctrl+V`
按键被原样送给正在跑的程序：自己会读系统剪贴板的 TUI（Claude Code 就是）因此还能拿到图片。
剪贴板里同时有文本和图片时，按文本处理。

代价是 `Ctrl+V` 不再作为 `^V` 字符到达 shell（vim 的可视块选择、readline 的 quoted-insert 用得到
它）。这与 Windows Terminal 的默认行为一致；vim 里可以用 `Ctrl+Q` 代替。

终端输出里的 URL 可以直接点开。

## 5. SSH 快速连接

`Ctrl+Shift+S`（或标题栏的链路图标）打开连接框，输入目标后回车，新标签页里就是远程会话：

```
user@host                          最常见的形式
host:2222                          非默认端口（写成 -p 2222 也一样）
user@host -i C:\keys\id_ed25519    额外参数原样传给 ssh
```

它**走系统自带的 OpenSSH 客户端**（`ssh.exe`，Windows 10 起内置），不是自研协议栈：密钥、agent、
`known_hosts`、`~/.ssh/config` 的行为与你在命令行敲 `ssh` 完全一致，首次连接的指纹确认也照常出现在
终端里。开了会话恢复时，SSH 标签会记住连接目标，下次启动自动重连（重新建立的连接，不是断点续传）。

- 裸 IPv6 地址（`::1`、`user@2001:db8::7`）直接写即可；只有「唯一一个冒号 + 结尾纯数字」才会被
  当成端口，所以 IPv6 要指定端口时用 `-p`。
- 额外参数按空格切分后原样传给 ssh，含空格的路径暂不支持引号包裹。
- 连接结束后 pane 的去留看 **ssh 的退出码**：连不上、认证失败、`ssh.exe` 不存在（非零退出）都会
  以红字留在 pane 里，挂了多久才失败无所谓；远端正常登出（退出码 0）则像本地 shell 的 `exit`
  一样关闭 pane。
- 回车时输入无法解析（比如只有选项没有目标）会红框抖动提示，不会静默吞掉。

## 6. 设置

`Ctrl+,` 或点齿轮打开。**任何改动立即生效并立即写盘**，没有"应用"或"保存"按钮；按 `Esc`、点面板
外侧或右上角 `✕` 关闭。

面板底部显示配置文件路径，也可以直接手改那个文件（下次启动生效）。

### 外观

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 主题 | 暗夜 | 整套一起换：终端调色板、辉光、标签栏、极光浓度、颗粒与暗角都跟着走。可选暗夜 / 樱野 / 苔庭 / 琥珀（暗色）与晨白（浅色） |
| 字体 | Cascadia Code → Cascadia Mono → Consolas → 微软雅黑 | CSS `font-family` 写法，逗号分隔的回退链 |
| 字号 | 13.5 | 6–40 |
| 玻璃浓度 | 50% | 终端表层染色的深浅，越低越透（0% 时几乎只剩系统毛玻璃） |
| 极光背景 | 开 | 背后缓慢旋转的紫青色光晕 |
| 光标辉光 | 开 | 光标的霓虹辉光与拖尾 |
| 启动动画 | 开 | 启动时的扫描线 |

### 终端

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 光标样式 | 方块 | 方块 / 竖线 / 下划线 |
| 光标闪烁 | 关 | 默认关是因为辉光本身在呼吸，两个节奏会打架 |
| 连字 | 关 | 把 `=>` `!=` 这类序列交给字体渲染成连字；需要字体本身支持（Cascadia Code、Fira Code 等） |
| 回滚行数 | 10000 | 每个 pane 各自保留的历史行数，0–500000 |
| 默认 shell | 自动 | 留空则依次探测 `pwsh.exe` → `powershell.exe` → `cmd.exe`；也可以填完整路径 |
| 起始目录 | 自动 | 留空则用用户主目录。从命令行带目录启动时（见第 9 节）以命令行为准 |

改主题、字体、字号、光标、连字、回滚行数会**立刻应用到所有已开的 pane**，不需要重开。改默认 shell 和
起始目录只影响之后新建的 pane。

在面板的输入框里打字不会触发全局快捷键；录制热键时按下的组合也只会被录制，不会顺带执行。

## 7. 恢复上次会话

打开后，程序会把**标签页、每个标签页的分屏布局与比例、每个 pane 的 shell 与工作目录，
以及窗口的位置和大小**记在 `state.json` 里，下次启动照原样重建 —— 就算你中途改过默认 shell，
恢复出来的也是各 pane 当时被指定的那个（"自动探测"的 pane 恢复时会重新探测，所以探测目标被
卸载也不会坏）。

关于工作目录，有一点需要知道：终端本身没法知道 shell 现在在哪个目录，只能靠 shell 主动汇报
（OSC 7 或 OSC 9;9 转义序列）。装了 shell 集成的 PowerShell 会汇报，恢复时就能回到原来的目录；
没有汇报的 shell 则回到设置里的起始目录。

其它细节：

- 快照在布局变动后约 0.6 秒写盘，所以就算异常退出，最多丢掉最后一次改动。
- **只恢复布局，不恢复内容**：每个 pane 都是全新的 shell，滚动历史和正在跑的程序不会回来。
- 关掉这个开关时会顺手删掉 `state.json`，不会留一份几个月前的旧布局在那里。
- Quake 模式开着时不恢复窗口几何 —— 那时窗口位置由 Quake 说了算。

## 8. Quake 下拉模式

模仿 Quake 主机台的下拉终端：按一个全局热键，窗口从屏幕顶部落下；再按一次收起。

打开后窗口会**置顶**并且**不出现在任务栏**里。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用全局热键 | 关 | |
| 热键 | ``Ctrl+` `` | 点一下输入框再按组合键即可录制；**必须**含 Ctrl / Alt / Shift / Win 中至少一个 |
| 下拉高度 | 45% | 占屏幕工作区高度的比例，20%–100%，宽度总是整屏 |
| 失焦自动隐藏 | 开 | 点到别的程序时自动收起 |

行为细节：

- 窗口落在**鼠标当前所在的显示器**上，多屏时热键按在哪块屏就落在哪块。
- 热键按下时：窗口在前台 → 收起；窗口被别的程序挡住或已隐藏 → 落下并取得焦点。
- 热键被别的程序占用（或组合键不合法）时，面板底部会用红字提示，而不是假装绑上了 —— 启动时就
  注册失败也一样，打开设置面板就能看到。
- 热键没能注册成功时，**失焦自动隐藏会暂停生效**：一个既不在任务栏、又唤不回来的隐藏窗口等于
  失踪，所以宁可让它留在屏幕上。
- 关掉开关后置顶和任务栏行为会立刻恢复正常。

## 9. 从命令行启动

把 `nighterminal.exe` 放进 PATH（改名成 `ntps` 之类的短名字更顺手），就可以在任何目录敲一下，
新窗口直接开在那个目录：

```sh
ntps                # 开在当前目录
ntps D:\work        # 开在指定目录
ntps -d D:\work     # 同上；--cwd / --directory 也认
```

- 命令行给的目录**优先于设置里的"起始目录"**：在某个目录敲命令是一次明确的动作，设置只回答
  "什么都没指定时开在哪"。
- 这个目录对该窗口**整个生命周期**有效，新开的标签页也在那里；分屏出来的 pane 仍然优先继承
  当前 pane 的目录（第 3 节）。
- **双击 exe、从开始菜单或快捷方式启动时不算数**：那时候的"当前目录"是 exe 自己所在的目录，
  不是谁指定的，按它开窗口只会莫名其妙地盖掉设置。这种情况仍然走设置里的起始目录。
- 目录不存在就当没给。写错的选项会被跳过而不是报错 —— 它是个窗口程序，没有控制台可以打印用法。

## 11. 文件位置

都在 `%APPDATA%\dev.nighterminal.app\`：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 设置面板里的全部配置 |
| `state.json` | 上次会话的标签与分屏布局（只在"恢复上次会话"打开时存在） |

两个文件都可以手改。`config.json` 读得很宽松：缺字段用默认值，数值超范围会被收敛回合法区间，整个
文件坏掉也只是退回默认设置，不会导致程序起不来。

## 12. 已知限制

- **工作目录的记录依赖 shell 集成**（OSC 7 / OSC 9;9）。没有集成的 shell，分屏继承目录和会话恢复
  都会退回起始目录。
- **恢复会话不恢复滚动历史和运行中的程序**，只恢复布局与目录。
- **毛玻璃需要 Windows 11**。Windows 10 会退到 Mica 或不透明背景，此时状态栏右下角会显示 `solid`，
  界面不会因此错乱。
- **连字是内置的常见序列表**（`=>` `!=` `->` 等约 60 个），不解析字体文件 —— 个别字体的花式连字
  （比如 Fira Code 把 `www` 连起来）不在其列。
- **浅色主题下，自带配色的程序不一定跟着变**。终端会如实回答"我的底色是什么"（`OSC 11`），但很多程序
  根本不问，只按"终端是暗的"选色 —— PSReadLine 的语法高亮就是一例，浅底下个别 token 会淡到看不见。
  这类程序得改它自己的配色（PSReadLine 用 `Set-PSReadLineOption -Colors`，Claude Code 有自己的主题设置）。
  同理，认定终端是暗色的 TUI 刷的黑色填充在浅色主题下会保留成黑条：把它抹平只会让它的浅色文字掉进浅色背景。
- **SSH 依赖系统的 OpenSSH 客户端**：`ssh.exe` 不在 PATH 里时连接会以红字失败。含空格的参数
  （如带空格的密钥路径）暂不支持。
