# Nighterminal 使用说明

一个 Windows 上的半透明毛玻璃终端。后端是 Rust + ConPTY，前端是 xterm.js，所以它跑的是真正的
PowerShell / cmd，不是模拟器。

---

## 1. 界面

```
┌──────────────────────────────────────────────────────────┐
│ ▶_  [ powershell ×] [ nighterminal ×]  +      ⚙ ─ □ ✕   │  标题栏 / 标签栏
├──────────────────────────────────────────────────────────┤
│                                                          │
│  PS C:\Users\you>                    │                   │  终端区（可分屏）
│                                      │                   │
│                                      ├───────────────────┤
│                                      │                   │
├──────────────────────────────────────────────────────────┤
│ ● powershell / 103×24   2 panes           DOM / acrylic  │  状态栏
└──────────────────────────────────────────────────────────┘
```

**标题栏**：左边是标签页，`+` 新建；右边齿轮是设置，然后是最小化 / 最大化 / 关闭。中间空白处可以
拖动窗口，双击最大化。

**状态栏**（从左到右）：

| 项 | 含义 |
| --- | --- |
| ● | 绿色＝shell 正常，红色＝shell 已退出 |
| `powershell` | 当前 pane 跑的是哪个 shell |
| `103×24` | 当前 pane 的列数×行数 |
| `2 panes` | 当前标签页分了几屏（未分屏时不显示） |
| `DOM` | xterm 使用的渲染器 |
| `acrylic` | 系统给到的毛玻璃材质：`acrylic` / `mica` / `solid`（无毛玻璃时会自动改用不透明背景） |

全屏 TUI（vim、htop、lazygit、Claude Code 等）接管画面时，状态栏会自动收起把整个窗口让出去，
退出后自动回来。

---

## 2. 标签页

| 操作 | 方式 |
| --- | --- |
| 新建 | `Ctrl+Shift+T`，或点 `+` |
| 关闭 | 标签上的 `×`、中键点标签，或 `Ctrl+Shift+W` |
| 切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab`，或 `Ctrl+PageDown` / `Ctrl+PageUp` |
| 跳到第 N 个 | `Ctrl+Alt+1` … `Ctrl+Alt+9` |

标签名跟着 shell 报告的标题走，并会压缩成最后一段：`D:\Projects\Nighterminal` 显示成
`Nighterminal`，`powershell.exe` 显示成 `powershell`。

在 shell 里敲 `exit` 会关掉所在的 pane；如果那是标签页里最后一个 pane，标签页跟着关；关掉最后一个
标签页则退出程序。

**shell 起不来时不会静默消失**：如果 shell 在 1.5 秒内就退出（通常是配置里的 shell 路径写错了），
这个 pane 会留在屏幕上并打出一行红字，标签上的圆点变红，方便你看清错误再手动关掉。

---

## 3. 分屏

| 操作 | 快捷键 |
| --- | --- |
| 向右切一屏 | `Ctrl+Shift+D` |
| 向下切一屏 | `Ctrl+Shift+E` |
| 移动焦点 | `Alt+←` `Alt+→` `Alt+↑` `Alt+↓` |
| 关闭当前 pane | `Ctrl+Shift+W` |

可以任意嵌套：先左右切，再对右半边上下切，就得到"左边一整列 + 右边两格"。

- **拖动分隔条**可以调整比例，最小 8%。
- **焦点 pane** 会有一圈很淡的青色描边，未聚焦的 pane 字会稍微变暗；鼠标点哪个 pane 就切到哪个。
- **新 pane 继承当前 pane 的工作目录**（需要 shell 集成，见第 6 节），否则用设置里的起始目录。
- `Alt+方向键` 是**按屏幕位置**找最近的邻居，不是按分割树的结构 —— 嵌套之后"树上的邻居"经常不是
  眼睛看到的那个。

---

## 4. 复制粘贴

| 操作 | 方式 |
| --- | --- |
| 复制选区 | `Ctrl+Shift+C`，或选中后点右键 |
| 粘贴 | `Ctrl+V` 或 `Ctrl+Shift+V`，或没有选区时点右键 |
| 选择 | 鼠标拖选 |

`Ctrl+C` **没有被拦截**，它始终作为中断信号送给 shell —— 这是终端里 `Ctrl+C` 该有的行为，要复制
请用 `Ctrl+Shift+C`。

粘贴走的是 xterm 的 `paste()`，所以 shell 要求 bracketed paste 时会被正确遵守（多行内容不会被
逐行执行）。

终端输出里的 URL 可以直接点开。

---

## 5. 设置

`Ctrl+,` 或点齿轮打开。**任何改动立即生效并立即写盘**，没有"应用"或"保存"按钮；按 `Esc`、点面板
外侧或右上角 `✕` 关闭。

面板底部显示配置文件路径，也可以直接手改那个文件（下次启动生效）。

### 外观

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 字体 | Cascadia Code → Cascadia Mono → Consolas → 微软雅黑 | CSS `font-family` 写法，逗号分隔的回退链 |
| 字号 | 13.5 | 6–40 |
| 玻璃浓度 | 50% | 终端表层染色的深浅，越低越透（0% 时几乎只剩系统毛玻璃） |
| 极光背景 | 开 | 背后缓慢旋转的紫青色光晕 |
| 光标辉光 | 开 | 光标的霓虹辉光与拖尾 |
| 启动动画 | 开 | 启动时的扫描线 |

### 终端

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 光标样式 | 方块 | 方块 / 竖线 / 下划线 |
| 光标闪烁 | 关 | 默认关是因为辉光本身在呼吸，两个节奏会打架 |
| 回滚行数 | 10000 | 每个 pane 各自保留的历史行数，0–500000 |
| 默认 shell | 自动 | 留空则依次探测 `pwsh.exe` → `powershell.exe` → `cmd.exe`；也可以填完整路径 |
| 起始目录 | 自动 | 留空则用用户主目录 |

改字体、字号、光标、回滚行数会**立刻应用到所有已开的 pane**，不需要重开。改默认 shell 和起始目录
只影响之后新建的 pane。

| 恢复上次会话 | 关 | 见第 6 节 |

## 6. 恢复上次会话

打开后，程序会把**标签页、每个标签页的分屏布局与比例、每个 pane 的工作目录，以及窗口的位置和大小**
记在 `state.json` 里，下次启动照原样重建。

关于工作目录，有一点需要知道：终端本身没法知道 shell 现在在哪个目录，只能靠 shell 主动汇报
（OSC 7 或 OSC 9;9 转义序列）。装了 shell 集成的 PowerShell 会汇报，恢复时就能回到原来的目录；
没有汇报的 shell 则回到设置里的起始目录。

其它细节：

- 快照在布局变动后约 0.6 秒写盘，所以就算异常退出，最多丢掉最后一次改动。
- **只恢复布局，不恢复内容**：每个 pane 都是全新的 shell，滚动历史和正在跑的程序不会回来。
- 关掉这个开关时会顺手删掉 `state.json`，不会留一份几个月前的旧布局在那里。
- Quake 模式开着时不恢复窗口几何 —— 那时窗口位置由 Quake 说了算。

## 7. Quake 下拉模式

模仿 Quake 主机台的下拉终端：按一个全局热键，窗口从屏幕顶部落下；再按一次收起。

打开后窗口会**置顶**并且**不出现在任务栏**里。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用全局热键 | 关 | |
| 热键 | ``Ctrl+` `` | 点一下输入框再按组合键即可录制；**必须**含 Ctrl / Alt / Shift / Win 中至少一个 |
| 下拉高度 | 45% | 占屏幕工作区高度的比例，20%–100%，宽度总是整屏 |
| 失焦自动隐藏 | 开 | 点到别的程序时自动收起 |

行为细节：

- 窗口落在**鼠标当前所在的显示器**上，多屏时热键按在哪块屏就落在哪块。
- 热键按下时：窗口在前台 → 收起；窗口被别的程序挡住或已隐藏 → 落下并取得焦点。
- 热键被别的程序占用（或组合键不合法）时，面板底部会用红字提示，而不是假装绑上了。
- 关掉开关后置顶和任务栏行为会立刻恢复正常。

## 8. 快捷键总表

| 组合 | 作用 |
| --- | --- |
| `Ctrl+Shift+T` | 新建标签页 |
| `Ctrl+Shift+D` | 向右分屏 |
| `Ctrl+Shift+E` | 向下分屏 |
| `Ctrl+Shift+W` | 关闭当前 pane（最后一个则关闭标签页） |
| `Alt+方向键` | 切换焦点到相邻 pane |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签页 |
| `Ctrl+PageDown` / `Ctrl+PageUp` | 同上 |
| `Ctrl+Alt+1`…`9` | 跳到第 N 个标签页 |
| `Ctrl+Shift+C` | 复制选区 |
| `Ctrl+V` / `Ctrl+Shift+V` | 粘贴 |
| `Ctrl+,` | 打开 / 关闭设置面板 |
| `Esc` | 关闭设置面板（面板未开时交给 shell） |
| 右键 | 有选区则复制，否则粘贴 |
| 中键点标签 | 关闭该标签 |
| 双击标题栏空白 | 最大化 / 还原 |

快捷键按**物理按键位置**匹配，换非美式键盘布局也不会错位。

## 9. 文件位置

都在 `%APPDATA%\dev.nighterminal.app\`：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 设置面板里的全部配置 |
| `state.json` | 上次会话的标签与分屏布局（只在"恢复上次会话"打开时存在） |

两个文件都可以手改。`config.json` 读得很宽松：缺字段用默认值，数值超范围会被收敛回合法区间，整个
文件坏掉也只是退回默认设置，不会导致程序起不来。

---

## 10. 已知限制

- **工作目录的记录依赖 shell 集成**（OSC 7 / OSC 9;9）。没有集成的 shell，分屏继承目录和会话恢复
  都会退回起始目录。
- **恢复会话不恢复滚动历史和运行中的程序**，只恢复布局与目录。
- **毛玻璃需要 Windows 11**。Windows 10 会退到 Mica 或不透明背景，此时状态栏右下角会显示 `solid`，
  界面不会因此错乱。
- 暂不支持：SSH、标签页拖拽重排、pane 换位、字体连字。
